Part I — Foundations#

Why this matters#

Understanding Git as a system of snapshots prevents confusion later.

Concept Diagram#

Working Tree → Staging → Commit

Key Takeaways#

  • Git = snapshot system

  • 3 layers matter

Exercise#

  • add file

  • commit
